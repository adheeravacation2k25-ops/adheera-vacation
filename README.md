# Adheera Vacation - Premium Travel Website

A fully responsive, modern, premium-looking travel agency website built with React + Tailwind CSS + Framer Motion.

## Features

- **7 Pages**: Home, Explore, Packages, About, Contact, Destination Details, Booking
- **Premium UI/UX**: Glassmorphism effects, gradients, smooth animations
- **Responsive Design**: Mobile, tablet, and desktop optimized
- **Dark Mode Toggle**: Full dark/light mode support
- **Interactive Components**: Animated counters, scroll reveals, carousels
- **AI Chatbot**: Floating chatbot with suggested questions
- **Advanced Filtering**: Search, sort, filter by category/price/rating
- **Booking Flow**: Multi-step booking form with review and confirmation

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

```
src/
  components/
    ui/           # Reusable UI components
    sections/     # Page section components
    layout/       # Layout components (Navbar, Footer, Chatbot)
  pages/          # Page components
  data/           # Static data
  hooks/          # Custom hooks
  utils/          # Utility functions
```
